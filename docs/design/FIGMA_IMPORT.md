## Procédure Figma

1. Créer un fichier Figma « LivresGourmands — Wireframes Étape 3 ».
2. Pages recommandées : `Desktop`, `Mobile`, `Composants`.
3. Pour chaque SVG : **File → Place image / Import** ou glisser-déposer.
4. Convertir en frames éditables si besoin (détourage / outline).
5. Organiser horizontalement : Accueil → Produit → Panier → Checkout → Admin.
6. Ajouter des annotations (zones nav, contenu, CTA).
7. Publier le fichier et coller le lien réel dans `livrables/Liens.txt`.
